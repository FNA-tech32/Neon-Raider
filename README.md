## ✨ Features & Highlights

- ⚡ **High-Impact Brand Identity** — Custom Neon Raider aesthetic with refined color palettes, typography, and micro-interactions.
- 📱 **100% Fully Responsive Design** — Optimized for smartphones, tablets, laptops, and ultra-wide desktop monitors.
- 🔄 **Dual-Channel Communication System** — Clear separation of **Primary** channels (headquarters hotline, official corporate email, Austin HQ) and fast-response **Alternative** channels (direct WhatsApp line, priority support email, Seattle Tech Hub).

  - Font Awesome 5 (iconography across navigation, contact blocks, and footer)

## 🚀 Getting Started & Local Development

This project runs directly in any modern web browser without requiring a Node.js compilation build step.

### Option 1: Direct File Launch
Simply double click or open [`index.html`](file:///c:/Users/QBS%20Accounting/Documents/websites/Neon-Raider/index.html) in your preferred browser:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Apple Safari

### Option 2: Using VS Code Live Server
1. Open this workspace folder in VS Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right click `index.html` and select **"Open with Live Server"** (default port `http://127.0.0.1:5500`).

### Option 3: Using Python Built-in Server
Open your terminal in the project directory and run:
```bash
# Python 3
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

### Option 4: Using Node.js `npx serve` or `http-server`
```bash
npx serve .
# or
npx http-server -p 8080
```

## 🎨 Design System & Customization

The project uses a unified CSS custom property design system defined in [`assest/header.css`](file:///c:/Users/QBS%20Accounting/Documents/websites/Neon-Raider/assest/header.css):

```css
:root {
    --brand-color: #007FF9;        /* Electric Neon Blue */
    --button-bg-1: #FF5722;        /* Vibrant Accent Coral */
    --button-bg-2: #007FF9;        /* Primary Button Color */
    --white: #ffffff;              /* Crisp White */
    --black: #111827;              /* Deep Neutral Charcoal */
    --font: 'Poppins', sans-serif; /* Modern Typography */
}
```

To update colors, branding accents, or contact links, simply modify the root variables in [`assest/header.css`](file:///c:/Users/QBS%20Accounting/Documents/websites/Neon-Raider/assest/header.css) and the respective page markup.
